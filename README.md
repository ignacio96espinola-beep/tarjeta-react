# Tarjetas de presentación en React

## Descripción

Aplicación desarrollada para practicar componentes funcionales,
JSX y el uso de props en React.

## Tecnologías

- React
- JavaScript
- Vite
- CSS

## Funcionalidades

- Componente reutilizable Tarjeta.
- Personalización mediante props.
- Visualización de tres tarjetas.
- Diseño adaptable a dispositivos móviles.

## Instalación y ejecución

1. Clonar este repositorio:

   git clone https://github.com/ignacio96espinola-beep/tarjeta-react.git

2. Ingresar a la carpeta:

   cd tarjeta-react

3. Instalar dependencias:

   npm install

   En Windows PowerShell: npm.cmd install

4. Iniciar el proyecto:

   npm run dev

   En Windows PowerShell: npm.cmd run dev
